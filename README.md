# Lista de Tarefas do Programador

Projeto desenvolvido para o Checkpoint 4 da disciplina de Front/Web da FIAP.

## Sobre o projeto

O projeto consiste em um sistema de gerenciamento de tarefas voltado para programadores.

A aplicação permite cadastrar novas tarefas, definir o nível de prioridade, marcar tarefas como concluídas, remover tarefas e filtrar a visualização entre todas, pendentes e concluídas.

As tarefas são armazenadas automaticamente no localStorage, permitindo que os dados continuem salvos mesmo após atualizar ou fechar a página.

## Funcionalidades

- Cadastro de tarefas
- Nome da tarefa
- Data
- Descrição
- Nível de prioridade
- Marcar tarefa como concluída
- Remover tarefas
- Filtro de todas as tarefas
- Filtro de tarefas pendentes
- Filtro de tarefas concluídas
- Armazenamento das tarefas no localStorage
